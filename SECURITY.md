# Security Policy

The full security policy, threat model, and vulnerability reporting process
live in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a Vulnerability

**Do NOT open public GitHub issues for security vulnerabilities.**

Use GitHub Private Vulnerability Reporting:

- Public binaries repo: <https://github.com/bpeers01/tkr-releases/security/advisories/new>
- Private source repo: <https://github.com/bpeers01/tkr/security/advisories/new>

See [docs/SECURITY.md](docs/SECURITY.md#reporting-vulnerabilities) for the
full disclosure timeline, what to include in a report, and the fallback
contact path.

## Supported Versions

Only the latest released version of `tkr` is supported. Security fixes are
shipped as patch releases against the current minor.
